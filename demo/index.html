About this demo

The full app is a RAG pipeline: Mistral embeddings + ChromaDB retrieve the 5 most relevant chunks, and Mistral Large writes an answer strictly from them.

This hosted version runs entirely in your browser, with no API key. It performs the retrieval step (BM25 over the same 1000-character chunks) and shows the passages the model would answer from.

Run the full app with your own Mistral key for generated answers.
